Does price follow the flow, or fade it? Runs in the background — it will not block the site.
Check proxy accuracy answers a different question: only Binance publishes the real buy/sell split, so multi-venue CVD can only ever use the bar-direction approximation. This grades that approximation against the real thing on the one venue where both exist. Uses 15m sub-bars.
Independent sampling is the honest setting: it takes one event per 24 bars so forward windows do not overlap. It cuts the event count ~24x, so only the largest buckets stay readable — that is the point. Every bar gives far more events but every t-stat is inflated.

30 symbols at 4h takes roughly 4–6 minutes. Requests are deliberately throttled so this cannot get the server rate-limited by Binance while the live scanner is running. Leave this page — the run continues; come back to read it.
